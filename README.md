 Train Coach Management System

 Description
This project demonstrates train coach management using HTML, CSS, and JavaScript.

 Features
- Add a coach at the beginning
- Add a coach at the end
- Remove a coach
- Display all coaches in sequence

Technologies Used
- HTML
- CSS
- JavaScript

 Sample Output
Coach1 → Coach2 → Coach3 → Coach4 → NULL

 How to Run
1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
3. Use the buttons to add, remove, and display coaches.

 Learning Objective
To understand basic list operations and how train coaches can be represented in a sequence.
